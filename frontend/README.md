# Frontend (Angular) — fase 5

Esta pasta é um espaço reservado. O Angular entra depois que a API de reservas estiver estável.

Quando chegar a hora:

```bash
npm install -g @angular/cli
ng new frontend --routing --style=scss --standalone --directory=.
```

O plano para o chat, a confirmação de ações (`PendingAction`) e a integração com o Compose está
em `docs/phase-0-guide.md` (seção "O que vem depois") e no documento de planejamento do projeto.
